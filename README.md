
# Microsoft Teams Automation

A simple tool to simulate your mouse movements to keep the status of the Microsoft Teams active.


**NOTE: The position of the Microsoft Teams application is assumed to be present in the bottom of the taskbar in Windows Operating System (OS). Please adjust the co-ordinates of the mouse cursor depending upon the position of Teams application and the Operating System in which the script runs.**


## Step 1: Clone the repository in your desired directory.
You can directly clone the repository in your desired directory or download the zip file.

- To clone:
```bash
git clone https://github.com/arhemanthkumar/Microsoft_Teams_Automation.git
```

## Optional Step: Create Virtual Environment.

- For Windows:

```bash
python -m venv .venv
```

```bash
.venv\Scripts\activate
```

- For macOS/Linux:

```bash
python3 -m venv .venv
```

```bash
source .venv/bin/activate
```

## Step 2: Install the required library files.
Run the below command from the working directory:
```bash
pip install -r requirements.txt
```

## Step 3: Run the Script.
You can either choose to run the **main_script.py** file from your favorite IDE ( such as *VScode*, *Pycharm*, *Vi* ) or run directly inside the working directory from the terminal using:

- For Windows:
```bash
python main_script.py
``` 

- For macOS/Linux:
```bash
python3 main_script.py
```
